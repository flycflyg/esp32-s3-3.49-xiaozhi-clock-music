# 安装说明

## 一、准备

### 硬件
- 微雪 **ESP32-S3-Touch-LCD-3.49** 开发板（**16 MB Flash 版本**）
- USB-C 数据线（能传数据，不是只能充电的线）
- TF 卡（可选，放音乐用，FAT32 格式）

### 软件
任选其一：

| 方式 | 适合谁 | 说明 |
|---|---|---|
| **命令行 esptool** | 有 Python 环境 | 最稳，能看到每一步结果，推荐 |
| 图形化 Flash Download Tool | Windows 用户 | 乐鑫官方工具，填地址和文件即可 |
| 浏览器网页刷机 | 不想装环境 | 需要 Chrome/Edge，部分板子兼容性一般 |

安装 esptool：

```bash
pip install esptool
```

macOS / Linux 查串口：

```bash
ls /dev/cu.usbmodem*      # macOS
ls /dev/ttyUSB* /dev/ttyACM*   # Linux
```

Windows 在「设备管理器 → 端口」里看，通常是 `COM3`、`COM4`。

## 二、刷机

### 情况 A：新板子，或想彻底重来

```bash
esptool.py --chip esp32s3 -p <串口> -b 460800 \
  write_flash 0x0 xiaozhi-3.49-custom-full.bin
```

**这一步会清空 WiFi 配置和激活状态**，刷完要重新配网（见第三节）。

### 情况 B：板子已经能正常开机对话，只想升级

```bash
esptool.py --chip esp32s3 -p <串口> -b 460800 \
  write_flash 0x20000 xiaozhi-3.49-custom-app.bin
```

**WiFi、激活状态、表情包、壁纸全部保留**，刷完自动重启。

### 刷不进去怎么办

如果报 `Failed to connect` / `No serial data received`，让板子进下载模式：

1. 按住 **BOOT** 键不放
2. 按一下 **RESET** 键
3. 松开 **BOOT**
4. 重新执行刷机命令

### 校验固件完整性

```bash
# macOS / Linux
shasum -a 256 xiaozhi-3.49-custom-app.bin
# Windows PowerShell
Get-FileHash xiaozhi-3.49-custom-app.bin -Algorithm SHA256
```

和 `SHA256SUMS.txt` 里对应的值比对，一致才说明文件没下坏。

## 三、首次开机

1. **上电**，屏幕亮起，设备进入配网模式
2. 手机 Wi-Fi 列表里找到设备发出的热点（名称类似 `Xiaozhi-XXXX`），连上去
3. 自动弹出的配置页面里填写：
   - 你家 WiFi 名称
   - WiFi 密码
4. 保存后设备重启并连接网络
5. 打开 [xiaozhi.me](https://xiaozhi.me) 控制台 → 添加设备 → 输入屏幕上显示的 **6 位验证码**
6. 激活成功后，对着设备说「**你好小智**」即可开始对话

> 配网与激活流程由官方固件提供，本项目未做改动。若界面与本说明略有出入，以官方文档为准。

---

## 四、放音乐（可选）

1. TF 卡格式化为 **FAT32**
2. 把 `.mp3` 文件拷到**根目录**（不要放子文件夹里，当前版本只扫描根目录）
3. 插卡，开机
4. 进入音乐界面即可看到歌曲列表

**支持中文文件名**（这是固件专门处理的，需要 `CONFIG_FATFS_API_ENCODING_UTF_8=y`）。

## 五、换表情包（可选）

表情包不在应用固件里，而在 **assets 分区**（地址 `0x800000`），需要用官方控制台生成。

### 步骤

1. 登录 [xiaozhi.me](https://xiaozhi.me) 控制台
2. 进入 **智能体 → 管理设备 → 自定义**
3. 在「表情集合」里上传你的 GIF：
   - 尺寸 **128×128**（本板表情框正好是这个尺寸）
   - 格式 GIF89a，透明背景，无限循环
   - 建议 10~12 fps、不超过 30 帧、256 色以内
   - 文件名对应情绪名：`neutral` `happy` `laughing` `funny` `sad` `angry` `crying` `loving` `embarrassed` `surprised` `shocked` `thinking` `winking` `cool` `relaxed` `delicious` `kissy` `confident` `sleepy` `silly` `confused`
   - **`neutral` 必须提供**，没指定的情绪会自动回落到 neutral 那张
4. 其他选项（字体、唤醒词、壁纸）**保持和原来一致**，否则界面外观会变
5. 生成后下载 `assets.bin`

### 刷入（顺序很重要）

```bash
# 1) 先擦除整个 8 MB assets 分区
esptool.py --chip esp32s3 -p <串口> -b 460800 erase_region 0x800000 0x800000

# 2) 再写入新资源包
esptool.py --chip esp32s3 -p <串口> -b 460800 write_flash 0x800000 assets.bin
```

> **为什么必须先擦除**：`write_flash` 只覆盖文件长度范围内的数据。官方生成的包通常只有 3 MB 左右，如果直接写进 8 MB 分区，后半段还是旧的文件，两套文件系统会撞对象 ID，结果可能是「表情没变」甚至挂载失败。

### 刷完检查

开机后看串口日志应该出现：

```
I (8239) Assets: The partition size is 8192 KB
I (8439) MODEL_LOADER: Successfully load srmodels
I (8469) Assets: Refreshing display theme...
```

有这三行就说明资源包挂载成功。

---

## 六、回滚到官方固件

1. 从 [xiaozhi-esp32 Releases](https://github.com/78/xiaozhi-esp32/releases) 下载对应版本的官方固件
2. 刷官方合并包到 `0x0`
3. 注意：官方固件刷完后 assets 分区仍是你的自定义表情，如果需要恢复出厂外观，要另外刷回官方的 `assets.bin`
