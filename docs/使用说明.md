# 使用说明

## 一、按键与触摸

| 操作 | 作用 |
|---|---|
| 说「**你好小智**」 | 唤醒对话 |
| 单击 **BOOT** 键 | 手动唤起 / 结束对话（音乐播放时也能用） |
| 触摸屏幕 | 从待机时钟回到对话界面 |
| 单击 **PWR** 键 | 开关机 |

---

## 二、待机翻页时钟

**什么时候出现**：设备进入待机状态 **3 秒**后自动出现，不需要任何操作。

**界面布局**：

```
┌──────────────────────────────────────┐
│  11       ┌──────────────┐    周五   │  ← 左：月日竖排
│  月       │              │    初三   │  ← 右：星期 + 农历
│  10       │      11      │           │      （外列星期，内列农历）
│  日       │              │           │
│  2026年   └──────────────┘           │  ← 中间：140px 翻页数字
└──────────────────────────────────────┘
```

- 中间的大号数字是小时/分钟（翻页动画）
- 左侧竖排：月 / 日，以及年份
- 右侧竖排：星期（外列）+ 农历（内列，如「十月初二」）
- 配色：纯黑底、深灰卡片、白字

**退出**：触摸屏幕或按 BOOT 键，立刻回到对话界面。

**时间准不准**：自动与服务器时间同步，不需要手动设置。农历由固件本地计算（内置 1900–2100 年数据），不联网。

---

## 三、音乐播放器

### 进入
从主界面进入音乐界面（触摸操作），自动扫描 TF 卡根目录的 `.mp3`。

### 界面说明

| 区域 | 内容 |
|---|---|
| 顶部 | 「本地音乐（N 首）」 |
| 中部 | 歌曲列表，当前播放项高亮 |
| 底部按钮 | 上一首 / 播放暂停 / 下一首 / 返回 |
| 播放键 | 红色底 + 白色符号（和其他按钮区分） |

### 播放时的自动行为

| 行为 | 说明 |
|---|---|
| 自动续播 | 一首播完自动接下一首，最后一首播完回到第一首 |
| 音量 | **跟随系统音量**，本固件不做任何限制或压缩 |
| 唤醒词 | **暂时失效**（防止喇叭声被麦克风拾取导致自问自答） |
| BOOT 键 | **仍然有效**，可以手动唤起对话 |
| 小智说话时 | 音乐自动暂停，说完自动继续 |

### 停止

| 操作 | 结果 |
|---|---|
| 暂停 | 音乐停下，唤醒词恢复可用 |
| 继续播放 | 从暂停处继续 |
| 退出音乐界面 | **停止播放** |

### 上一首 / 下一首
播放中可以直接连按，支持快速切换（不会出现「只换歌名不出声」的情况）。

## 四、音量

- 说「**音量调到 90**」或在 App 里调，语音和音乐都跟随这个值
- 建议从 **85~90** 开始。如果开到 95 以上出现「发毛」式失真，先看下一节 ——
  大概率不是软件问题

---

## 五、声音「发毛 / 破音」怎么排查（先做这个，30 秒）

**出现持续的「发毛、发破」声时，先用手按住外壳。**

| 现象 | 结论 |
|---|---|
| 按住就好、松开又坏，或按压位置/力度不同声音不同 | **机械共振**，不是固件问题 |
| 按住没变化 | 继续往下查（音源、喇叭本身、功放） |

**本板最常见的原因**：喇叭和硬壳之间那层缓冲胶**老化变薄**，喇叭与外壳形成刚性接触，
升温后（热膨胀）开始共振。典型症状：

- 用几分钟后才出现（不是一开机就有）
- 凉了会恢复，但**重启没用**（温度不会因为重启而降）
- 换音乐、降音量、刷固件全都无效

**处理**：拆开，在喇叭四周贴一圈 **1~2 mm 厚的泡棉双面胶**（或 EVA 泡棉）做柔性缓冲。
注意**别把喇叭背面完全封死**，小喇叭需要留一点空气腔，封死了声音会变闷、低频消失。

贴完之后整首歌、整段对话都应该干净，音量也可以正常开到 90~95。

## 六、关于语音响度增强（本版已关闭）

早期版本实现过一个「抬 RMS + 峰值限幅」的语音增强模块，用来让小智说话更响。
经过真机长会话测试后**默认关闭**了，原因：

- 小智的 TTS 逐句响度差一倍以上（峰值 43%~90%），
  任何「固定峰值上限」的设计都会让限幅器全程工作，反而更早出现失真
- 抬高增益会把持续功率推高，长会话更容易触发上面那个机械共振

**想要更响，直接调系统音量** —— 那是唯一干净的手段。源码里的模块保留了开关
（`main/audio/voice_enhance.cc` 的 `kEnabled`），需要时可以自行打开。

## 七、界面配色

### 音乐界面
- 背景：纯黑 `#000000`
- 文字：纯白 `#FFFFFF`
- 普通按钮：浅灰 `#CCCCCC` + 黑色符号
- 播放/暂停键：红色 `#E53935` + 白色符号
- 歌单行背景：深灰 `#262626`

### 主界面
- 字幕区域和状态栏背景**透明**，壁纸完整显示
- 聊天气泡保持原有样式

## 八、常见操作流程

### 想听歌
```
待机时钟 → 触摸屏幕 → 进音乐界面 → 选歌 → 播放
（音量跟随系统音量，唤醒词暂时失效，BOOT 键仍可用）
```

### 边听歌边和小智说话
```
播放中按 BOOT 键 → 音乐自动暂停 → 和小智对话 → 说完音乐自动继续
```

### 不想听了
```
退出音乐界面（点返回键）→ 自动停止播放
```

### 只想看时间
```
什么都不做，待机 3 秒 → 时钟自动出现
```
