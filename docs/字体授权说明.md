# 字体授权说明

本固件包含一个自定义位图字体，用于待机翻页时钟的大号数字。

## 字体来源

| 项目 | 内容 |
|---|---|
| 字体文件 | **Liberation Sans Bold** |
| 上游项目 | Liberation Fonts **2.1.5** |
| 项目主页 | https://github.com/liberationfonts/liberation-fonts |
| 授权协议 | **SIL Open Font License 1.1**（OFL-1.1） |
| 协议全文 | http://scripts.sil.org/OFL |
| 用途 | 生成 `main/display/font_clock_140_4.c`（0–9 与冒号，140 px，4 bpp） |

## 为什么选它

Liberation Sans 是 **与 Arial 度量兼容**（metric-compatible）的开源字体 ——
字符的 advance width（前进宽度）与 Arial 完全相同，因此换用后翻页时钟的排版、
字距、居中位置都保持不变，观感几乎一致，同时**没有任何商业字体授权风险**。

实测对比（本项目）：

| 项目 | Arial Bold（旧） | Liberation Sans Bold（现用） |
|---|---|---|
| 数字 advance width | 1246（全部 10 个） | 1246（全部 10 个，**完全相同**） |
| 冒号 advance width | 746 | 746 |
| line_height | 103 | 100 |
| 位图数据 | 34 KB | 35 KB |

## OFL 1.1 要点（摘要，非法律文本）

- ✅ 可自由使用、研究、修改、再分发，**包括商用**
- ✅ 可以随软件一起打包、嵌入、再分发
- ⚠️ 字体本身**不能单独售卖**
- ⚠️ 修改后的衍生字体**不能使用保留字体名**（Reserved Font Name：`Liberation`）
- ⚠️ 衍生字体**必须继续使用 OFL 协议**发布

本项目只是把 Liberation Sans Bold **渲染成位图字体数据**（未修改字形轮廓），
随固件一起分发，属于上述「bundled with software」的情形，完全合规。

## 如何重新生成

```bash
# 安装转换器（Node.js）
npm install -g lv_font_conv

# 下载字体
# https://github.com/liberationfonts/liberation-fonts
# 或 Debian 包 fonts-liberation2 内 usr/share/fonts/truetype/liberation2/LiberationSans-Bold.ttf

# 生成（参数必须一致，否则排版会变）
lv_font_conv \
  --font LiberationSans-Bold.ttf \
  -r 0x30-0x3A \
  --size 140 \
  --bpp 4 \
  --format lvgl \
  --no-compress \
  --lv-include lvgl.h \
  -o main/display/font_clock_140_4.c
```

> ⚠️ 生成后注意两点：
> 1. 变量名是 `font_clock_140_4`（`standby_clock.cc` 里是 `LV_FONT_DECLARE(font_clock_140_4)`）
> 2. 不要把 `--size` 改成别的值 —— 时钟布局的像素偏移是按 140 px 调的
