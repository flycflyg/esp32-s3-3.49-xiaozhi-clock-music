# 常见问题（FAQ）

## 刷机相关

### Q：刷完屏幕不亮 / 一直重启

**排查顺序**：

1. 确认板子是 **16 MB Flash** 版本（8 MB 版本装不下分区布局）
2. 确认刷的是 `0x0` 全量包（`xiaozhi-3.49-custom-full.bin`），不是 app 包刷错地址
3. 抓串口日志（115200 波特率）看有没有 `abort()` / `Guru Meditation`
4. 如果日志里有 `rst:0x15 (USB_UART_CHIP_RESET), boot:0x8 (SPI_FAST_FLASH_BOOT)` 是正常的软复位

### Q：报 `Failed to connect to ESP32-S3: No serial data received`

进下载模式：

1. 按住 **BOOT** 不放
2. 按一下 **RESET**
3. 松开 **BOOT**
4. 重跑刷机命令

### Q：刷完 WiFi 和激活信息没了

刷 `0x0` 全量包会覆盖 NVS 分区（WiFi 密码、激活状态都存在这里）。这是正常现象，重新配网激活即可。

**只想升级、不想重新配网** → 只刷 app 包：

```bash
esptool.py --chip esp32s3 -p <串口> write_flash 0x20000 xiaozhi-3.49-custom-app.bin
```

## 唤醒词相关

### Q：喊「你好小智」没反应

**最常见原因：唤醒词模型和音频前端（AFE）不匹配。**

本板必须用 **FD 系列**的 AFE 配置（通话型 AEC 会导致唤醒词失灵）：

```
AEC(FD_LOW_COST, NLP_VERY_AGGRESSIVE)
```

判断方法：抓串口日志，看有没有这行

```
I (10229) AFE: AFE Pipeline: [input] -> |AEC(FD_LOW_COST, NLP_VERY_AGGRESSIVE)| -> |VAD(WebRTC)| -> |WakeNet(wn9_nihaoxiaozhi_tts,)|
```

如果是 `AEC(SR_LOW_COST...)` 就是配置错了。

### Q：放着音乐的时候喊不醒

**这是设计如此**：音乐播放期间主动忽略唤醒词，防止喇叭声音被麦克风拾取导致自问自答。

- 想和小智说话：按 **BOOT 键**，或先暂停音乐
- 暂停状态下唤醒词是有效的

### Q：自己跟自己说话 / 一直误触发

同样是回声问题。检查：
1. 音乐播放期间唤醒词屏蔽是否生效
2. AFE 的 AEC 配置是否正确
3. 音量是否过大（喇叭离麦克风太近）

## 音乐相关

### Q：中文歌名显示成乱码 / 方块

必须启用 FATFS 的 **UTF-8 API 编码**，不是代码页问题：

```
CONFIG_FATFS_API_ENCODING_UTF_8=y
```

**踩过的坑**：改成代码页 936（GBK）没用，改成 `ANSI_OEM` 也没用。关键是 API 编码方式，不是代码页数字。

### Q：音乐或小智说话有「发毛 / 破音」，而且是用了几分钟后才出现

**先做这件事：失真的时候用手按住外壳。**

- **按住就好、松开又坏**，或按压位置/力度不同声音不同 → **机械共振**，跟固件无关
- 按住没变化 → 继续往下查

本板最常见的原因是：**喇叭和硬壳之间那层缓冲胶老化变薄**，喇叭与外壳形成刚性接触，
升温后（热膨胀）开始共振。

典型症状（对上了基本就是它）：

- 开机时不明显，用几分钟后才出现
- 凉了会恢复，但**重启没用**（温度不会因为重启而降）
- 换音乐、降音量、刷固件、换音源全都无效

**处理**：拆开，在喇叭四周贴一圈 **1~2 mm 厚泡棉双面胶**（或 EVA 泡棉）做柔性缓冲。
**别把喇叭背面完全封死** —— 小喇叭需要留空气腔，封死了声音会变闷、低频消失。

贴完后再测，整首歌、整段对话都应该干净，音量也能正常开到 90~95。

> 这个坑很能迷惑人：数字侧完全干净（峰值 31%~73%、满幅样本 0、内存稳定、电压稳定），
> 换另一条音频通路（音乐）也同样失真。排查过程详见 README 的「一次长达一天的音频失真排查」。

### Q：音量开到多少合适

建议 **85~90**。语音和音乐都跟随这个值（本固件不做任何音量限制或压缩）。

如果你开到 95 以上出现「发毛」式失真，先按上一条排查 —— 大概率是机械共振，不是软件问题。

### Q：为什么没有语音响度增强 / 声音没有变得更响

早期版本做过，后来**关闭**了。原因：小智的 TTS 逐句响度差一倍以上（峰值 43%~90%），
任何「固定峰值上限」的设计都会让限幅器全程工作，反而更早出现失真；抬高增益又会推高持续功率，
更容易触发机械共振。

**想要更响，直接调系统音量** —— 唯一干净的手段。源码里的模块保留了开关
（`main/audio/voice_enhance.cc` 的 `kEnabled = false`），需要时可以自行打开。

### Q：一首歌播完就停了，不会自动播下一首

v1.1 起已修复：一首播完自动接下一首，最后一首播完回到第一首循环。

实现上要注意：**不能在播放任务里直接调 `PlayFile()`** —— 任务自己还没 `vTaskDelete`
的时候栈没释放，立刻再申请 6 KB 栈会创建失败。正确做法是播放任务正常结束时置一个
「自然播完」标志，由界面的 500 ms 定时器消费后起下一首。

### Q：退出音乐界面后，小智的声音变小了 / 音量变成 75

这是 v1.0 修过的一个 bug，v1.1 起已取消音乐音量限制，正常版本不会出现。如果自己改代码：

1. 退出界面时是否真的调用了 `Stop()`（只 `Hide()` 界面不会停音乐）
2. 音量限制是否用的是「**不写 NVS**」的临时设置接口

`SetOutputVolume()` 会把音量持久化到 NVS，一旦用它做限制，75 就变成了用户偏好，怎么调都回不去。必须用 `SetOutputVolumeTemporary()`。

### Q：点「下一首」第一次只换歌名不出声，要按两次

播放任务栈还没释放就创建新任务，内部 SRAM 不够（播放时只剩 13~14 KB）。修法是：等旧任务真正退出（`task_alive_` 标志）+ 创建重试。

### Q：只能看到根目录的歌

当前版本只扫描 TF 卡根目录，不支持子文件夹。把 mp3 直接放根目录。

### Q：能不能放无损 / flac / wav

当前只解码 mp3。其他格式需要另加解码器。

## 显示相关

### Q：屏幕方向反了 / 触摸点不准

两个独立的设置：

| 问题 | 改哪里 |
|---|---|
| 画面方向 | `custom_lcd_display.cc` 里的 `LV_DISPLAY_ROTATION`（本板用 `270`） |
| 触摸坐标 | 触摸驱动里的坐标变换（本板 `x = 639 - raw_x`、`y = 171 - raw_y`） |

**踩过的坑**：画面旋转和触摸旋转会叠加，改完方向后如果点击位置偏了，不要再去改画面旋转，要改触摸坐标变换。

### Q：屏幕太暗

本板背光受 **TCA9554 IO 扩展芯片的 EXIO1** 控制。如果 EXIO1 输出被写成 0，屏幕就是黑的。

**关键坑**：TCA9554 是独立供电的，**输出锁存状态跨 SoC 复位、跨刷固件一直保留**，只有彻底断电才会清。所以「刷完固件屏幕变暗」很可能不是固件问题，而是这个锁存器被之前的操作写坏了。

### Q：待机时钟不出现

- 确认设备真的进入了 idle 状态（不是一直在对话）
- 时钟是**覆盖层**，等待 3 秒才出现
- 抓日志看有没有 `StandbyClock: 待机时钟就绪` 和 `时钟界面已建立`

### Q：时钟时间不对

**不要给固件加时区设置**。服务端下发时间时已经做过时区偏移（`ts += timezone_offset * 60000`），再加一次 `TZ=CST-8` 会多 8 小时。

### Q：农历显示不对

内置 1900–2100 年数据表，超出范围不显示。闰月按「闰X月」命名。

## 表情包相关

### Q：刷了 assets.bin 之后表情没变

1. **没擦除就写了**：`write_flash` 只覆盖文件长度范围，旧数据残留会导致读取到旧文件。必须先 `erase_region 0x800000 0x800000`
2. 检查是否刷到了 `0x800000`（不是 `0x20000`）
3. 抓日志看 `Assets: The partition size is 8192 KB` 和 `Refreshing display theme`

### Q：刷完表情包，桌面图标变了 / 字体变小了

官方控制台生成的 `assets.bin` 是**整套资源**（表情 + 字体 + 唤醒词模型 + 壁纸 + 配置），不是只换表情。

**避免方法**：在控制台生成时，字体、唤醒词、壁纸**全部保持和原来一致**，只改表情那一栏。

### Q：为什么刷完表情包，很多情绪长得一样

官方生成器要求必须提供 `neutral` 图，**没指定的情绪会自动回落到 neutral 那张**。想每个情绪都不一样，就把 21 个都上传。

### Q：`robot_2` 是什么

服务端会下发这个情绪名，但官方表情包里没有对应图片，会回落到字体符号。不影响使用。

## 编译相关

### Q：编译报 `'class Application' has no member named 'GetStateMachine'`

版本对不上。本固件基于 **v2.4.2**（commit `e8d8a40`），请 checkout 到对应 tag 再套改动。

### Q：编译报找不到 `lv_font_conv`

时钟大数字字体需要先生成。用 `lv_font_conv` 生成 140 px 字体文件，或者直接用仓库里的 `font_clock_140_4.c`。

### Q：`%lld` 打印出来是 `ld`

ESP-IDF 的 printf 不支持 `%lld`。改用 `%d` + `(int)` 强转。

### Q：改了 sdkconfig 但没生效

`sdkconfig.defaults.esp32s3` 会覆盖 `sdkconfig.defaults`。target 相关的配置必须写在 **target 专用文件**里。

## 其他

### Q：电量显示不准 / 充电状态不对

本板没有充电检测引脚，充电状态是软件估算的，不准是正常的。电压测量本身是准的（ADC1 通道 3 = GPIO4，3:1 分压）。

### Q：能不能用其他型号的板子

不行。引脚、屏幕驱动、音频芯片、分区布局全都不同。本项目只针对 **ESP32-S3-Touch-LCD-3.49**。

### Q：支持在线音乐 / 网络电台吗

不支持，网络电台功能已被移除。本固件只保留 TF 卡本地音乐。
