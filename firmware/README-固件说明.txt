固件说明（请先读完再刷）
========================================

本目录有两个固件文件，用途不同，别搞混：

────────────────────────────────────────
1) xiaozhi-3.49-custom-full.bin   3,289,168 字节
────────────────────────────────────────
用途：全量刷机（新板子 / 想从干净状态开始 / 救砖）

包含：bootloader + 分区表 + 启动槽信息 + 应用固件
烧录地址：0x0

命令：
  esptool.py --chip esp32s3 -p <串口> -b 460800 write_flash 0x0 xiaozhi-3.49-custom-full.bin

⚠️ 注意：会清空 WiFi 配置和激活状态（NVS 分区被置空，
   这样包内不携带任何人的 WiFi 密码与激活凭据）。
   刷完需要重新配网 + 在 xiaozhi.me 重新激活。


────────────────────────────────────────
2) xiaozhi-3.49-custom-app.bin    3,158,096 字节
────────────────────────────────────────
用途：只升级应用固件（板子已经能正常开机对话）

烧录地址：0x20000

命令：
  esptool.py --chip esp32s3 -p <串口> -b 460800 write_flash 0x20000 xiaozhi-3.49-custom-app.bin

✅ 不会动 WiFi 配置、激活状态、表情包、壁纸。
   刷完自动重启即可。


────────────────────────────────────────
⛔ 千万不要刷的分区
────────────────────────────────────────
  0x800000   assets 分区（字体 / 表情 GIF / 唤醒词模型 / 壁纸）

这里放的是整套 UI 资源，刷错版本会改掉桌面图标、字体大小、
甚至唤醒词。只有在你明确要换表情包时才动它，
而且必须先擦除整个 8 MB 分区再写入：

  esptool.py --chip esp32s3 -p <串口> -b 460800 erase_region 0x800000 0x800000
  esptool.py --chip esp32s3 -p <串口> -b 460800 write_flash 0x800000 assets.bin


────────────────────────────────────────
刷不进去怎么办
────────────────────────────────────────
报 Failed to connect / No serial data received 时，进下载模式：

  1. 按住 BOOT 键不放
  2. 按一下 RESET 键
  3. 松开 BOOT
  4. 重跑命令


────────────────────────────────────────
校验文件完整性
────────────────────────────────────────
在【发布包根目录】执行（SHA256SUMS.txt 用的是带路径的形式）：

  macOS/Linux:  shasum -a 256 -c SHA256SUMS.txt
  Windows:      Get-FileHash firmware\xiaozhi-3.49-custom-app.bin -Algorithm SHA256

两个文件都应该输出 OK / 与 SHA256SUMS.txt 中的值一致。

本版本（v1.2）的期望值：
  应用固件  0587e412b12e1e99…  3,158,096 字节
  全量镜像  2d9beaef134865f3…  3,289,168 字节


────────────────────────────────────────
硬件要求
────────────────────────────────────────
  微雪 Waveshare ESP32-S3-Touch-LCD-3.49
  ESP32-S3R8 / 8 MB PSRAM / 16 MB Flash  ← 必须是 16 MB Flash 版本
  3.49 寸 172×640 屏 + ES8311 + ES7210 + TF 卡槽

其他型号的板子不能刷。
